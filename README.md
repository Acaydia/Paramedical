# Paramedical Knowledge Base

An early-stage workspace for organizing paramedical reference material, learning notes and source-aware documentation.

## Purpose

This project provides a structured home for an educational reference library as material is developed and reviewed. Clear topic organization, reliable sources and thoughtful privacy practices are the priorities.

**Current status:** The repository contains this overview and editor configuration. A topic-specific reference library has not yet been added.

## Start here

- [Project overview](README.md): Purpose, scope and current status.
- [Contribution guide](CONTRIBUTING.md): Expectations for sourcing, review and privacy.
- [Editor configuration](.vscode/): Workspace settings; not clinical reference content.

## Content standards

Future references should identify their intended audience, cite authoritative sources, include a review date, and clearly distinguish general education from local protocols. Organize files by topic and label unfinished or unreviewed material rather than presenting it as approved guidance.

Suggested sections include foundations, topic notes, source lists and educational templates. These are planning ideas, not folders or resources already provided by this repository.

## Educational use and privacy

Material is for education and reference only, not patient-specific medical advice. It does not replace professional assessment, appropriate training, supervision, organizational protocols or local scope-of-practice requirements.

Do not commit patient-identifying information, identifiable treatment photographs, confidential records, credentials or private correspondence. Use hypothetical examples and only share material you have permission to use.
